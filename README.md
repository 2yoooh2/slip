# SSG 영수증 PDF 추출기

SSG 영수증 PDF를 업로드하면 **주문일자 · 제품명 · 구매금액 · 수량**을 자동으로 추출해서 Excel에 바로 붙여넣을 수 있게 해주는 정적 웹페이지입니다.

서버나 빌드 과정 없이 `index.html`을 브라우저로 열기만 하면 동작합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다. (더블클릭 또는 로컬 서버로 열기)
2. SSG 영수증 PDF 파일을 업로드합니다. (파일 선택 버튼 또는 드래그 앤 드롭, 여러 개 동시 선택 가능)
3. 추출된 상품 목록이 표로 표시됩니다. 여러 파일을 올리면 모든 영수증의 상품이 한 표에 합쳐집니다. 필요하면 각 셀을 직접 수정하거나 행을 삭제할 수 있습니다.
4. **전체 상품 복사** 버튼을 누른 뒤, Excel에서 **B열의 시작 셀**을 선택하고 `Ctrl+V`로 붙여넣습니다.
   - 주문일자는 B열, 제품명은 C열, 구매금액은 E열, 수량은 G열에 입력됩니다.

## 프로젝트 구조

```
index.html              메인 페이지
css/style.css           스타일
js/parser.js            PDF.js 좌표 기반 SSG 영수증 파싱 로직
js/script.js            업로드/표 렌더링/복사·삭제 등 UI 로직
js/lib/                 PDF.js 라이브러리 (오프라인 vendor)
sample/영수증.pdf        테스트용 샘플 SSG 영수증
```

## 파싱 방식

PDF.js의 `getTextContent()`로 얻은 텍스트 아이템의 좌표(x, y)를 이용해 판매자 / 제품명 / 수량 / 구매금액 열을 구분합니다.

- x좌표로 열을 구분해 판매자명이 제품명에 섞이지 않도록 합니다.
- 제품명이 여러 줄로 잘려 있으면 수량·구매금액이 나오기 전까지 한 줄로 합칩니다.
- `옵션`으로 시작하는 줄은 제품명에서 제외합니다.
- 수량(`개`)과 구매금액(`원`)이 함께 확정되는 지점을 상품 한 건의 끝으로 판단합니다.
- `구매내역합계`, `면세품가액`, `과세물품가액`, `구매합계`, `기타비용`, `결제내역` 등이 나오면 추출을 종료합니다.
- 영수증 상단의 `주문번호`(예: `2026-08-05-1C5547`, 년-월-일-주문번호)에서 월.일만 뽑아 `08.05` 형식(Excel 표기용, `-` 대신 `.`)으로 변환해 모든 상품 행에 함께 넣습니다. (발급일시는 실제 발급 시각이라 주문일과 다를 수 있어 사용하지 않습니다)

## 기술 스택

- HTML / CSS / Vanilla JavaScript
- [PDF.js](https://mozilla.github.io/pdf.js/) (로컬 vendor, CDN 미사용)
- Clipboard API

서버, Python, 외부 프레임워크는 사용하지 않습니다.
